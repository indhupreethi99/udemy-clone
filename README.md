Udemy Clone (HTML & CSS)

This project is a simple Udemy homepage clone built using only HTML and basic CSS. It is designed to replicate the look and feel of the Udemy platform while focusing on front-end layout and styling skills.

🚀 Features
Responsive navigation bar with logo and menu links
Search bar UI design
Category menu section
Hero banner section with call-to-action
Course cards layout using CSS Grid/Flexbox
Clean and simple footer section
Fully responsive design for mobile and desktop
🎯 Objective

The main goal of this project is to practice and improve front-end development skills, especially:

HTML semantic structure
CSS styling techniques
Layout design using Flexbox/Grid
Responsive web design
🛠️ Technologies Used
HTML5
CSS3




💡 What I Learned
Building structured web pages using HTML
Styling components with CSS
Creating responsive layouts
Improving UI design sense
